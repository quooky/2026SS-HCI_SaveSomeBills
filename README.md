# 📦 SaveSomeBills - Energie Managment App

> Mit SaveSomeBills soll es dem Endnutzer moeglich sein, potenzielle _Stromfresser_ in seinem Haushalt zu identifizieren und Verbesserungsvorschlaege bekommen wie, wo Storm gespart werden kann.
